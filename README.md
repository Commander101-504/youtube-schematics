# YouTube Schematics
A collection of schematics for @Commander1O1 on YouTube

Find the build you are looking for and download it for free

# Mod Requirements
**NJ Transit Bus** - [Create](https://modrinth.com/mod/create), [Create Aeronautics](https://modrinth.com/mod/create-aeronautics), [Create: Interiors](https://modrinth.com/mod/interiors), [Create: Connected](https://modrinth.com/mod/create-connected), [Create: Aeroworks](https://modrinth.com/mod/create-aeroworks), [Create: Copycats+](https://modrinth.com/mod/copycats), [Create: Dreams & Desires](https://modrinth.com/mod/create-dreams-and-desires), [Create Offroad: Narrow Roads](https://www.curseforge.com/minecraft/mc-mods/create-offroad-narrow-roads) - Note: Not all mods support schematics correctly, such as narrow roads, which shows as a regular wheel mount. Use the compact wheel mount.
